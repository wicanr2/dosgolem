# 204 — 疊字層：圖面（畫點陣圖，不跟文字互相移除）

狀態：**DRAFT**
日期：2026-09-30
前置：[`202-translation-overlay.md`](202-translation-overlay.md)（`Stamp`、逐格失效）、
[`203-baked-text-watchers.md`](203-baked-text-watchers.md)（`Watcher`）

---

## 1. 問題

`202`／`203` 的疊字只畫得出「字型 ＋ 字碼」。要把原版的圖換成高解析度版本，
需要在同一層畫**任意點陣圖**。

直接沿用 `Stamp` 會撞到三件事：

1. **內容**：`Stamp` 只有 `Font` ＋ `Text`。
2. **格子是一維橫排**（`Cells`／`CellW`／`CellH`）。整張圖是二維的。
3. **`Add` 的重疊移除**：`Owner` 非空的疊字（watcher 建的）只要重疊就整筆移除
   （`layer.go`，`203` §2.1 的規則）。一張蓋住整條面板的圖會把上面的譯文全部刪掉；
   下一幀 watcher 補回來，又把圖打成半透明。**兩邊互相拆台。**

第 3 點是關鍵：圖與字**本來就該同時存在、互不干涉**，
重疊移除的前提（「同一塊畫面只能有一個說法」）對它們不成立。

## 2. 規格

### 2.1 圖面

`Layer` 多一組疊字，與文字疊字分開：

```go
type Layer struct {
    Stamps []*Stamp // 文字（既有）
    Art    []*Stamp // 圖（本規格）
    ...
}

func (l *Layer) AddArt(s *Stamp)
func (l *Layer) DropArt(key string)
func (l *Layer) ClearArt()
```

- **重疊移除只在同一組內發生。** `AddArt` 只跟 `Art` 比，`Add` 只跟 `Stamps` 比。
- `Frame` 對兩組都做定色、指紋與逐格失效，規則與 `202` §2.3 完全相同。
- `Draw` 先畫 `Art` 再畫 `Stamps`：**字一定在圖上面。**
- `Watcher.Make` 回傳的疊字進哪一組，由 `Stamp.Art` 欄位決定（見 §2.2）。

### 2.2 點陣圖疊字

`Stamp` 增加兩個欄位：

```go
type Stamp struct {
    ...
    Art bool    // true：進 Art 組，用 Pix 畫，不用 Font／Text
    Pix []uint8 // RGBA，寬 = CellW*Cells*scale、高 = CellH*scale（見 §2.3）
}
```

- `Art` 為 true 時 `Font`／`Text`／`GlyphX`／`GlyphY`／`GlyphScale`／`SwapColors`／`FG`／`BG` 全部忽略。
- `Pix` 的 alpha ＝ 0 的像素不畫（讓圖自己決定哪裡透明）。
- 失效規則不變：逐格判斷，某一格的原版指紋改了就遮掉那一格（`Transparent[i]`），
  該格的像素整格不畫。**這正是「原版在圖上面畫了別的東西時自動破洞」的行為。**
- 錨定格規則（`202` §2.6）照舊。

### 2.3 倍率

`Pix` 是**已經放大好的**像素，倍率由呼叫端決定並在 `AddArt` 時固定。
`Draw(dst, scale, ...)` 的 `scale` 與 `Pix` 的倍率不符時**不畫這一筆**，
並呼叫 `OnDrop(s, "scale")`。

理由：縮放要在疊字層裡做，就得在這裡決定取樣方式，而不同素材要的取樣方式不同
（面板要 nearest 保銳利、人物要平滑）。**這個決定屬於呼叫端。**

### 2.4 二維

一張圖切成**每列一筆疊字**（一筆 ＝ 一橫排格子，沿用既有的一維格子）。
呼叫端自己切，本規格不提供切圖函式。

理由：`Stamp` 的一維格子已經被定色、指紋、錨定、捲動凍結四套邏輯依賴，
改成二維要動到全部四套。**每列一筆**沿用全部既有行為，成本是多幾筆疊字。

### 2.5 快照

`Art` 組要進 `Snapshot`／`Restore`，與 `Stamps` 同樣處理。
`Pix` **不進快照**（會讓快照大好幾個數量級）：還原時 `Pix` 為 nil 的疊字直接丟掉，
由呼叫端重新登記，`Watcher` 下一幀補上（同 `203` §2.3 對 watcher 的處理）。

## 3. 驗收

1. 一筆 `Art` 疊字與一筆文字疊字完全重疊：兩筆都在，`Draw` 的輸出是「字蓋在圖上」。
   反向對照：同組內兩筆重疊時，舊的照 `202` 的規則被移除或遮格。
2. 逐格失效：原版在 `Art` 疊字的第 n 格畫別的東西 → 該格不畫、其餘照畫；
   改回來 → 該格恢復。
3. `Pix` 的 alpha ＝ 0 的像素不改 `dst`。
4. 倍率不符時不畫，且 `OnDrop` 收到 `"scale"`。
5. 快照往返：`Art` 疊字的中繼資料保存、`Pix` 不在快照裡；
   還原後重新登記再 `Frame`，不會重複加。
6. 成本：1,000 格的 `Art` 疊字 ＋ 既有文字疊字，`Frame` 的時間相對只有文字疊字時
   的增幅要量出來（不設門檻，只要有數字）。

## 4. 不做

- 縮放、旋轉、混色模式（呼叫端給的就是最終像素）。
- 圖檔格式解碼。
- 在畫面上搜尋位置（沿用 `203`：只比對登記的座標）。
