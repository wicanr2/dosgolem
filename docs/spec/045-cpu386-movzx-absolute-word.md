# 045 — 386 絕對位址 word 零擴充讀取

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 037`](../re/037-fd2-second-callback-movzx.md)

- 實作 `0F B7 /r` 的 `mod=0, r/m=5, disp32` 形式，從 DS 描述子指定的線性
  位址讀取 16 位元值，零擴充後寫入 ModRM `reg` 指定的 32 位元暫存器。
- 必須經過 DS 描述子界限檢查；讀取失敗時維持失敗即關閉。
- 其他 `0F B7` 定址形式、前綴及目的寬度不由本切片授權。
- 固定 FD2 必須由 LE 入口自然經第二回呼抵達 `0x460C6`，並驗證
  EAX=`0x0000127F`、ESP=`0x55690`。

驗收包含獨立 CPU 單元測試、固定雜湊整合測試及命令列探針收據。

2026-09-06：單元測試、固定雜湊整合測試、探針及全套 Go 回歸通過；探針於
344 步抵達 `0x460C6`，EAX=`0x127F`、ESP=`0x55690`。
