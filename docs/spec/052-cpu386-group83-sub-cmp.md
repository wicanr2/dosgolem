# 052 — 386 群組 83 的 SUB 與絕對位址 CMP

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 044`](../re/044-fd2-third-callback-global-gate.md)

- `83 /5` 支援 `mod=3` 暫存器形式，以符號擴充 imm8 執行 32 位元 `SUB` 並
  更新算術旗標。
- `83 /7` 支援 `mod=0, r/m=5, disp32`，經 DS 描述子讀取 32 位元值，與符號
  擴充 imm8 比較，只更新算術旗標而不寫回。
- 其他新群組、定址形式與前綴維持失敗即關閉。
- 固定 FD2 由 LE 入口自然抵達 `0x4CC10`，驗證 EBP=`0x55680`、
  ESP=`0x5567C`、`[0x537FC]=0`、ZF=1。

驗收包含兩個獨立 CPU 單元測試、固定雜湊整合測試與探針收據。

2026-09-06：兩個單元測試、固定雜湊整合測試、探針及全套 Go 回歸通過；
探針於 471 步抵達 `0x4CC10`，EBP=`0x55680`、ESP=`0x5567C`、ZF=1。
