# 011 — XMS 最小集（DOSJP 的字型倉庫）

日期：2026-09-06

## 1. 定位

Config.5 有 `DEVICE=HIMEM.SYS`——**原版環境本來就有 XMS**。
DOSJP 把整份 JIS.FNT（286 KB）搬進 XMS，base memory 只留下
小小的常駐 handler；沒有 XMS 它印「XMS memory not found!」然後離開。
（286 KB 留在 base 也「能跑」，但 MAIN.EXE 的映像約 380 KB，
兩者在 640 KB 裡放不下——XMS 是這條鏈的必要條件，不是加分項。）

XMS 是 DOS 的標準驅動介面（HIMEM.SYS），換一支 binary 還成立
→ 機器層（`internal/dos`）。

## 2. 量測證據（2026-09-06，cmd/probe，dosgolem-yuan trampoline 版）

DOSJP.COM（帶 ` -F:font.dat -TJ`）：

1. `AH=49h` 釋放環境、`AX=6300h` 取 DBCS 表（`010`）、
   直接寫 IVT 掛走 int 10h／15h／21h；
2. `AH=4Ah` 縮自己的區塊 → `AH=48h` 要 0x45E8 段（286 KB）
   → 開 JIS.FNT → 連讀 10 次 32 KB（全部經 int F2h trampoline，
   **證明 `004` §2.1 的機制有效**）；
3. `int 2Fh AX=4300h`（XMS 存在性）→ 我們沒實作、AL 回 0，
   DOSJP 判定無 XMS → AH=09h 印「XMS memory not found!」→ `AH=4Ch`。
   收據：`yuan/workplace/boot-20260906-02/dosjp-xms.txt`。

之後的路（從反組譯，`yuan/org_game/DOSJP.COM` 檔案位移 0x3B8 起，
**強證據**——還沒跑到）：

4. `AX=4310h` 取 driver entry，存到 `[0114]`；
5. `AH=09h`（allocate EMB，DX ＝ KB）→ handle 存 `[0118]`；
6. `AH=0Bh`（move EMB）：把 base 裡的 286 KB 字型搬進 EMB
   （`b4 0b / be 1a 01 / call far [0114]`，描述子在 011A），
   搬完 `AH=49h` 釋放 base 那 286 KB；
7. `AH=31h DX=0110h` 常駐（只留 4.25 KB）。

## 3. 實作範圍（照 §2 的量測，不多做）

- `int 2Fh AX=4300h`：回 `AL=80h`（有 XMS）。
- `int 2Fh AX=4310h`：回 `ES:BX` → driver entry。entry 是 StubSeg 裡的
  trampoline：`CD F5h / CF`（陷阱向量 `int F5h`，與 `004` §2.1 同型）。
- XMS 服務（經 `int F5h` 分派，呼叫時 AH ＝ 功能號）：

| AH | 功能 | 實作 |
|---:|---|---|
| `00h` | Get XMS Version | AX ＝ 0200h（2.0）、BX ＝ 0、DX ＝ 0（無 HMA） |
| `08h` | Query Free Extended Memory | AX ＝ DX ＝ 8192（KB） |
| `09h` | Allocate Extended Memory Block | DX ＝ KB → 回 DX ＝ handle；失敗 CF＋BL |
| `0Ah` | Free Extended Memory Block | DX ＝ handle → AX ＝ 1 |
| `0Bh` | Move Extended Memory Block | DS:SI → 描述子（見下）→ AX ＝ 1 |

- Move 描述子：`+0 dword 長度`、`+4 word 來源 handle`、`+6 dword 來源位移`、
  `+0Ah word 目的 handle`、`+0Ch dword 目的位移`。**handle 0 表示
  常規記憶體**，此時位移欄是 far 指標（segment:offset）。
- EMB 內容是 Go 端的 `map[uint16][]byte`——**延伸記憶體不在 1 MB
  位址空間裡**，本來就讀不到，不必找地方放。
- handle 從 1 起編。長度為奇數的 move 照搬（XMS 2.0 要求偶數，
  但我們不挑）。
- 其他 AH：記一筆（`004` §1.3）。

## 4. 不做的事

- HMA／UMB／AH=0Ch 之後的功能（lock、realloc、A20）。
- 不做容量上限的誠實模擬（8192 KB 是宣告，不是限制）。
