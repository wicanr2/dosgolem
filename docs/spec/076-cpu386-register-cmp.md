# 076 — 386 暫存器間 CMP

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 054`](../re/054-fd2-watcom-delay-init-time.md)

- 支援無前綴 `39 /r` 且 `mod=3` 的 32 位元 `CMP r/m32,r32`。
- 沿用 32 位元 subtraction 旗標，不修改任一暫存器。
- 記憶體 ModRM 與所有新前綴形狀維持失敗即關閉。
- 固定 FD2 在 `0x3DCB3` 比較前後兩次 DOS 秒值，決定是否離開第一個等待迴圈。

2026-09-06：暫存器不變、ZF 與固定 delay 第一迴圈測試通過。
