# Buck Rogers 技術技能配置生命週期

狀態：**CONFORMED**

本規格核准 `buckrogers-text-receipt` 從固定 state 經正常角色建立路徑與職業技能 Escape→`Y`
進入技術技能配置畫面，量測列選取、加後減、拒絕離開與確認離開至角色身體圖示選擇畫面。
這是診斷規格，不授權改寫點數、技能規則、角色資料或存檔格式。

## 固定輸入

- 共用前綴沿用 spec 027，並於 #102,700,000 Escape、#102,900,000 `Y` 進入技術技能畫面。
- 選取分支：#103,600,000 Down；停止於 #105,000,000，預期 297 筆事件。
- 可逆減點分支：#103,600,000 Enter、#103,700,000 Right、#103,800,000 Enter；停止於
  #105,000,000，預期 299 筆事件。
- 拒絕離開分支：#103,600,000 Escape、#103,800,000 `N`；停止於 #106,000,000，預期
  290 筆事件。
- 確認離開分支：#103,600,000 Escape、#103,800,000 `Y`；停止於 #106,000,000，預期
  296 筆事件。
- 每條分支從同一 state 獨立重跑兩次；不得 direct-entry、記憶體注入或自動配置點數。

## 生命週期契約

- Down 依序以一般色重畫第一列四欄，再以選取色重畫第二列四欄。
- 預設動作 Enter 合法加一點；Right 本身沒有 dispatcher 完成事件，後續 Enter 以五筆事件
  還原同一列及剩餘點數。終點必須逐 byte 等於技術技能零點／Right-only 畫面。
- Escape 顯示一筆未用點數確認 identity；`N` 後終點逐 byte 等於技術技能基線。
- Escape→`Y` 進入角色身體圖示選擇畫面；正式收據固定確認提示與新畫面的六筆文字事件，
  但不保存原版英文全文。
- 動態點數只以 identity 與終點像素驗證，不列為譯文。

## 驗收

- 四條正式分支各兩次 JSON、64,000-byte indexed framebuffer 逐 byte 相同。
- verifier 固定 state、原版程式、命令、289-event 技術技能基線、完整 BIOS 排程與新增事件；
  減點與拒絕分支另比對各自同狀態參考畫面，任一漂移皆失敗即關閉。
- 專案正反例、真實 verifier、全部正式 dosgolem packages test／vet 及相關 race detector
  通過後，本規格才能升為 CONFORMED。

## 符合性紀錄（2026-09-21）

- 選取、可逆減點、拒絕離開與確認離開四條分支各從相同 state 重播兩次；每對 JSON 與
  framebuffer 逐 byte 相同。
- 四條分支事件數依序為 297／299／290／296；收據 SHA-256 依序為 `bc00c32c…df2f`、
  `f5098964…dc22`、`99fee634…49de`、`e28828f1…10b6`。
- 專案 88 項測試與真實 verifier 通過；全部正式 dosgolem packages test／vet 與 Buck Rogers
  相關 race detector 通過。
