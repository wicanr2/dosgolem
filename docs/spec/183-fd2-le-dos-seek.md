# 183 — FD2 LE DOS AH=42h 檔案定位

狀態：**CONFORMED**
日期：2026-09-06
前置：[`RE 125`](../re/125-fd2-dos-seek-mdi-ini.md)、
[`spec 140`](140-fd2-le-dos-open-readonly.md)

- `FD2StartupDOS` 在 `INT 21h/AH=42h` 接手已登錄唯讀控制代碼的定位。
- AL 僅接受 0、1、2，分別對應檔首、目前位置、檔尾；`CX:DX` 視為有號
  32 位位移。
- 成功時清 CF，將無號 32 位新位置寫入 `DX:AX` 的低 16 位，保留 EAX、EDX
  高 16 位。
- 未登錄控制代碼回傳錯誤 6；無效模式、定位失敗、負位置或超過 32 位位置
  回傳錯誤 1 並設定 CF。若底層定位後才發現結果無效，必須嘗試回復原位置。
- 不改寫檔案內容，不擴充其他 DOS 服務。

## 驗收條件

- 合成測試覆蓋三種起點、有號負位移、無效控制代碼、無效模式、失敗時位置
  不變，以及 `DX:AX` 與高 16 位保存。
- 固定雜湊 FD2 自然執行 `0x3CC1E`，確認 BX 是已登錄控制代碼，服務後抵達
  `0x3CC20`、CF 清除且 `DX:AX` 為有效新位置。
- 有界自然執行記錄下一個失敗即關閉位址，不順帶放寬後續服務。

## 驗證收據

- 固定雜湊 FD2 自然執行抵達 `0x3CC1E`；BX 是已登錄的 `MDI.INI`
  控制代碼，服務後抵達 `0x3CC20`、CF 清除，且 `DX:AX` 回傳的位置落在
  218-byte 檔案範圍內。
- 合成測試通過檔首／目前位置／檔尾、有號負位移、無效控制代碼、無效模式、
  失敗位置復原，以及 EAX／EDX 高 16 位保存。
- 強制重建後的有界自然探針抵達下一個失敗即關閉位址 `0x3CC20`：
  opcode `36h`（SS segment override）尚未支援。本規格未順帶放寬該 prefix。
