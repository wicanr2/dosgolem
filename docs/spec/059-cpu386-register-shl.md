# 059 — 386 暫存器 SHL

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 050`](../re/050-fd2-third-callback-allocation-consumer.md)

- 在既有 `C1 /5` 暫存器右移之外，支援無前綴、`mod=3` 的 `C1 /4 ib`
  32 位元左移。
- 位移量依 386 規則遮罩成五位元；非零位移更新結果與邏輯旗標，CF 取最後
  移出的位元。零位移不改暫存器與旗標。
- 其他群組、記憶體 ModRM 與前綴維持失敗即關閉。
- 固定 FD2 以 `0x4CC62` 的 `C1 E0 02` 計算第二段 `_nmalloc` 大小，並由
  LE 入口自然走到第二次配置返回 `0x4CC70`。

2026-09-06：左移結果、CF／ZF 與固定雜湊第二段大小計算驗證通過。
