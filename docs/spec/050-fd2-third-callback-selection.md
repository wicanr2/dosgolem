# 050 — FD2 第三筆啟動回呼選擇

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 042`](../re/042-fd2-third-callback-selection.md)

- 不新增 CPU 指令或更改記錄格式，重用已閉合的分派器掃描與間接 `CALL`。
- 固定 FD2 由 LE 入口自然執行，在前兩筆 status=2 後進入第三次被選中的回呼
  `0x4CBFD`；不得直接設定 EIP、EBX 或記錄狀態。
- 驗證 EBX=`0x539DA`、EAX=`0x4CBFD`、ESP=`0x55698`，該筆 status 在回呼
  入口仍為 0。
- 第二 byte、非物理順序的排程規則與回呼高層用途保持未知；回呼內容不屬於
  本切片。

驗收包含獨立固定雜湊整合測試與命令列探針收據。

`0x4CBFD`，EAX=`0x4CBFD`、EBX=`0x539DA`、ESP=`0x55698`。
