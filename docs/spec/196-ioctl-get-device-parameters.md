# 196 — 取磁碟裝置參數（int 21h AH=44h AL=0Dh CL=60h）

狀態：READY（已實作＋單元測試＋原版對拍驗證）
日期：2026-09-10
適用：`internal/dos/int21.go`

## 1. 為什麼需要它

程式要判斷「這是硬碟還是可換的媒體」時走的是 generic IOCTL 的
**取裝置參數**（`CL=60h`）。判斷不出來就當成軟碟，於是要求換片。

《Dungeon Master》DOS 版點過入口選單的 ENTER 之後就停在這裡：

```
┌──────────────────────────────────┐
│  PUT THE DUNGEON MASTER DISK     │
│           IN C:                  │
│              OK                  │
└──────────────────────────────────┘
```

觀測到的是**兩步退路**，而且兩步都落在「沒實作」：

| 步 | 呼叫 | 暫存器 | 意義 |
|---|---|---|---|
| 1 | `int 21h AH=44h AL=0Dh` | `BX=0003`（C:）、`CX=0860`、`DS:DX` ＝ 參數區塊 | 問裝置參數 |
| 2 | `int 13h AH=02h AL=01h` ×6 | `CX=0001 DX=0002`（磁柱 0／磁頭 0／磁區 1） | 退而求其次，直接讀開機磁區 |

⚠ **第 1 步之前的處置比「沒實作」更糟：它宣告成功但不填參數區塊**
（`AX=0`、`CF=0`），呼叫端因此拿自己堆疊上的垃圾當裝置型別用。
註解寫著「別讓成功假象藏住」，而那正是當時在做的事。

`CX=0860` 拆開是 `CH=08h`（磁碟裝置類別）、`CL=60h`（取裝置參數）。

## 2. 回傳的結構

呼叫端在 `DS:DX` 給一個區塊，我們填回去（Ralf Brown 的 INT 21/AX=440Dh/CL=60h）：

| 位移 | 大小 | 內容 | 我們填 |
|---|---|---|---|
| 00h | BYTE | 特殊功能（**輸入**：bit0 ＝ 要目前的 BPB） | 不動 |
| 01h | BYTE | 裝置型別 | `05h` ＝ 固定硬碟 |
| 02h | WORD | 裝置屬性（bit0 ＝ 不可移除） | `0001h` |
| 04h | WORD | 磁柱數 | 由幾何算出 |
| 06h | BYTE | 媒體型別 | `00h` |
| 07h | 31 B | 裝置 BPB | §3 |
| 26h | WORD | 每磁軌磁區數 | `63` |
| 28h | N WORD | 磁軌配置表 | **不填** |

**磁軌配置表只在輸入的 bit1 立起來時才有意義**，而立起來的呼叫端會自己
給表的長度。沒有長度就往下寫等於猜一個長度亂寫別人的記憶體。

`01h` 與 `02h` 這兩格是 DM 停在換片提示的直接原因：型別 `05h` ＋ 屬性
bit0 立起來合起來說的是「這是拔不下來的硬碟」，而換片提示的前提是
「這片拔得下來」。

## 3. BPB 要與 `AH=1Bh`／`1Ch` 一致

同一支程式可能兩邊都問。答案矛盾的話它算出來的可用空間會跳動，
而那種錯誤不會當場出現——存檔寫到一半才失敗。

`AH=1Bh` 目前回：每叢集 8 磁區、每磁區 512 位元組、40,000 叢集、媒體 `F8h`。
BPB 照這一組推：

| 欄位 | 值 | 來源 |
|---|---|---|
| 每磁區位元組 | 512 | `AH=1Bh` 的 `CX` |
| 每叢集磁區數 | 8 | `AH=1Bh` 的 `AL` |
| 保留磁區數 | 1 | 開機磁區 |
| FAT 份數 | 2 | 慣例 |
| 根目錄項數 | 512 | 慣例（32 磁區） |
| 總磁區數（16 位元） | 0 | 超過 65,535 要走 32 位元那格 |
| 媒體描述子 | `F8h` | `AH=1Bh` 寫的那一格 |
| 每 FAT 磁區數 | 157 | 40,000 項 × 2 位元組 ÷ 512，進位 |
| 每磁軌磁區數 | 63 | 慣例 |
| 磁頭數 | 16 | 慣例 |
| 隱藏磁區數 | 63 | 第一磁軌 |
| 總磁區數（32 位元） | 320,347 | 1 ＋ 2×157 ＋ 32 ＋ 40,000×8 |

磁柱數 ＝ ⌈(320,347 ＋ 63) ÷ (63 × 16)⌉ ＝ 318。

## 4. 邊界

- **只做 `CL=60h`。** 其他 generic IOCTL 子功能維持既有處置（記下來）。
  設參數（`CL=40h`）不做——我們沒有真的磁碟可以設。
- **不做每一台磁碟機各自的幾何。** `BL` 收下不用：我們只有一個 Root，
  §3 的那一組是所有磁碟機的答案。回報成固定硬碟對 A: 也一樣——
  問 A: 的程式本來就少，而回「可移除」會讓它開始問換片。
- **`int 13h` 讀磁區照舊回失敗**（`004` §）。IOCTL 答得出來就不必走那條退路；
  真要走的程式問的是磁區內容，那不是幾何問題，另案處理。

## 5. 驗收

1. 單元測試：`CL=60h` 之後區塊的裝置型別是 `05h`、屬性 bit0 立著、
   BPB 的每磁區位元組與 `AH=1Bh` 的 `CX` 相同。
2. 單元測試：呼叫端傳進來的 `[00h]` 不被覆寫。
3. 原版對拍：《Dungeon Master》DOS 版點 ENTER 之後不再出現換片提示
   （收據見 dungeon_master 專案的 `docs/verification/dosgolem-dm-boot-20260910.md`）。
