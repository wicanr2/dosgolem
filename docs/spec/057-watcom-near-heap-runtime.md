# 057 — Watcom 近堆執行期服務

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 049`](../re/049-fd2-watcom-nmalloc.md)

## 契約

- `cpu386.CPU` 提供可選的指令入口攔截介面。攔截器只有明確回報已處理時才可
  取代一般解碼；回傳錯誤時 `Step` 原樣回報，未處理時保持既有失敗即關閉行為。
- `machine.WatcomNearHeap` 由載入器、函式入口、最大容量明確建立；不得自行掃描
  或猜測任意 `_nmalloc` 位址。
- 已登錄入口採 32 位元 cdecl：`[SS:ESP]` 是返回位址、`[SS:ESP+4]` 是大小。
  成功後 EAX 是非零、四位元組對齊、互不重疊且可寫的平坦近指標；EIP 取返回
  位址，ESP 只增加 4，參數仍由呼叫者清除。
- 大小零、堆疊讀取失敗、位址溢位或超過容量時回傳零；除明確的零大小外，
  結構性錯誤不得偽裝成成功返回。
- 新增記憶體須清零，不得覆蓋 LE 已載入映像。相同輸入與配置順序必須得到
  相同位址。

## FD2 接線與驗收

固定雜湊 FD2 可把已證實入口 `0x36D26` 登錄給此服務。單元測試涵蓋未處理入口、
cdecl 返回、對齊、可寫性、不重疊與容量耗盡；整合測試必須由原始 LE 入口自然
走入第一次 `_nmalloc(1)`，返回 `0x4CC51` 且不得用直接設定 EIP 取代前置路徑。

2026-09-06：通用入口攔截、cdecl 返回、四位元組對齊、可寫性、不重疊、零大小、
容量耗盡及錯誤堆疊測試通過。固定雜湊整合探針由 LE 入口執行 486 步，第一次
`_nmalloc(1)` 回傳 `0x634D4`，EIP=`0x4CC51`、ESP=`0x55678`；全套 Go 回歸通過。
