# 056 — 386 SUB 讀取 EBP 堆疊位址

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 048`](../re/048-fd2-third-callback-first-allocation-call.md)

- `2B /r` 新增無前綴 `mod=1, r/m=EBP`、disp8 的 32 位元來源，經預設 SS
  描述子讀取，執行 `reg32 -= memory32` 並更新算術旗標。
- 讀取失敗不得修改目的暫存器；其他新記憶體形式與前綴維持失敗即關閉。
- 固定 FD2 由 LE 入口自然執行至 `0x36D26`，驗證堆疊參數為 1、
  ESP=`0x55674`、返回位址為 `0x4CC51`。

驗收包含獨立 SS 來源與失敗不提交測試、固定雜湊整合測試及探針收據。

2026-09-06：SS 來源／失敗不提交單元測試、固定雜湊整合測試、探針及全套
Go 回歸通過；探針於 485 步抵達 `0x36D26`，參數=1、返回位址=`0x4CC51`、
ESP=`0x55674`。
