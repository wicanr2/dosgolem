## 契約

依既有decodeAddress32選DS或SS，支援SIB與disp，未另擴充前綴。
堆疊容量足夠且讀取成功後，將原有效ST向後移一格，再發布ST(0)與深度。
空堆疊可載入，滿8格拒絕；未知延伸碼、暫存器形式、前綴與截斷拒絕。
來源記憶體、控制字、狀態字與整數旗標保留。既有DF E0 FNSTSW AX不變。
錯誤不發布FPU結果，EIP沿既有逐byte解碼政策。

有號16位整數可精確表示於現有float64堆疊；不擴充80位格式、tag／TOP、
x87例外或C1旗標模型，不宣稱完整硬體堆疊／逐旗標一致。

## 驗收

- 原DF442434，SS與DS基址不同，驗2-byte段尾讀取、符號及堆疊保留。
- -32768、-1、0、32767及空堆疊；高位元組不能被當作操作數。
- FILD → FMULP → MOVZX AX／MOV → FILD → FADDP一般指令銜接。
- 滿堆疊、段／實體越界、前綴、未知DF形式與截斷拒絕，不發布狀態。
- 完整cpu386／machine／FD2 oracle回歸與parity建置。
- 同SAV／seed／計畫重跑，舊2115點一致並越過26FDB。
