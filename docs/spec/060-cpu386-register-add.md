# 060 — 386 暫存器 ADD

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 050`](../re/050-fd2-third-callback-allocation-consumer.md)

- 支援無前綴 `01 /r` 且 `mod=3` 的 32 位元 `ADD r/m32,r32`，沿用既有
  `add32` 旗標規則。
- 記憶體 ModRM 與所有新前綴形狀維持失敗即關閉。
- 固定 FD2 以 `0x4CC68` 的 `01 C6` 合成第二段配置大小，並由 LE 入口自然
  走到第二次 `_nmalloc` 返回 `0x4CC70`。

2026-09-06：目的／來源暫存器與旗標單元測試、固定雜湊整合測試通過。
