# 015 — 最外層程式的命令列

狀態：READY
日期：2026-09-07

## 問題

`Load` 直接把執行檔載進機器，沒有經過 `EXEC`，所以 `PSP+80h`（命令列
尾巴：長度、文字、CR）是空的。靠參數決定要做什麼的程式因此走不進去。

實例：《銀河英雄傳說III SP》的 `ENDING.EXE` 的 `main` 先
`atox(argv[1])` 比 9、再 `atox(argv[2])` 比 1 或 2，都不合就印一行
橫幅然後 `return`。沒有命令列的話，跑幾千道指令就結束，看起來像
「這支程式什麼都不做」——而它其實是整個結局動畫。

## 介面

程式化：

```go
o, _ := oracle.Load(exe, root)
o.SetCmdLine(" 9 1")
```

命令列：

```
-cmdline " 9 1"
```

兩者都把「長度、文字、`0x0D`」寫進 `machine.PSPSeg` 的 `PSP+80h`，
上限 126 bytes（第 127 個位元組要留給 CR）。

## 邊界

命令列是**輸入的一部分**，與按鍵序列同一個地位：收據的 metadata 必須
記下來，否則同一組步數重跑會得到不同的結果。
