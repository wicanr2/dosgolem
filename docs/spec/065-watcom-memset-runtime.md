# 065 — Watcom `memset` 執行期服務

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 051`](../re/051-fd2-watcom-memset.md)

- 服務只處理明確登錄的 `memset` 入口；其他 EIP 回到 CPU 正常解碼。
- 採 32 位元 cdecl：目的地、值、長度位於 `[SS:ESP+4..12]`；只使用值的低 byte。
- 成功後 EAX 回傳原目的地、EIP 取返回位址、ESP 只移除返回位址。
- 零長度不存取目的地；非零範圍越界、堆疊不可讀或位址溢位必須回報錯誤，
  不得假裝成功。
- FD2 登錄已證實入口 `0x375C0`，與 `_nmalloc` 共用同一入口攔截鏈。

驗收涵蓋填值、回傳、零長度、越界與未登錄入口；固定原版須由 LE 入口自然完成
第三回呼的 environment 表建立並返回 `0x45DD3`。
