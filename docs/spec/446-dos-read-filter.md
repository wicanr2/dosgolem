# 446 — 讀檔過濾掛點

日期：2026-10-22

## 1. 規則

`DOS.ReadFilter func(name string, pos int64, data []byte)`：

| 項目 | 行為 |
|---|---|
| 時點 | `AH=3Fh` 從主機檔案讀到 n＞0 bytes 之後、寫進 `DS:DX` 之前 |
| name | 程式開檔時給的名字（`handle.name`，與 `FileOps` 同一個值） |
| pos | 這次讀取的起點（讀之前的檔案位置） |
| data | 實際讀到的 bytes，呼叫端可就地改寫；長度固定為 n |
| 不經過 | handle 0（標準輸入）、字元裝置、讀到 0 bytes |
| 主機檔案 | 不改。`FileOps`、`Reads` 照舊記錄，記的是讀取本身，不是內容 |

nil 時行為與之前完全相同。過濾器屬於呼叫端狀態，不進狀態檔；從狀態檔接著跑時由呼叫端重新設定。

## 2. 觸發案例

智冠中文版《魔法門 V》`XEEN.DAT` 每畫一個中文字，就 seek 到 `TEXTPAT.FNT` 的 `序號×30` 讀 30 bytes
（2 bytes Big5 碼加 28 bytes 字模），鐵匠鋪一個畫面就有數百次。前端要在不改原版檔、不改遊戲記憶體的前提下
即時切換繁體與簡體字形：在這個掛點把字模換成另一套字形即可，切換只影響之後畫的字。
