# 規格029：EOB1 LEVEL1首次轉向與前進

狀態：**CONFORMED**

## 證據與契約

由規格028的正常LEVEL1入口送Set 1方向鍵可證實原版地城使用硬體`INT 09h`路徑：

- `PageUp=49h`是數字鍵盤右轉；2,000,000道指令後第一人稱安全矩形`(0,0) 176×120`
  SHA-256為`a35855823bdecf7b0a150b2ca9d35e650234a644871c24a97ebb8d279cb45270`，畫面由封牆轉為東向通道。
- 接著`Up=48h`向前走入相鄰格；同矩形SHA-256為
  `7fc8b674d93e02578a2dfe79e54232899c4870bb2122e1b89eaf040477e72f08`，近端牆面位置隨前進改變。

兩步均使用原版鍵盤ISR，不呼叫滑鼠、不改座標、不直接修改地圖或角色狀態。人眼檢視確認指南針
右轉至東、隨後視點前移；累計四十四鍵make／break、八十八次port `60h`讀取。

## 相鄰失敗實驗

Set 1 `Right=4Dh`是向右平移而非旋轉；在入口可成功移到右側格，接著向前撞牆顯示
`YOU CAN'T GO THAT WAY.`。`Left=4Bh`在入口直接顯示相同拒絕訊息。這些結果只用來分辨輸入語意，
本規格不把碰撞分支納入正式adapter。

## 限制與停止線

本規格閉合入口右轉與一次成功前進，不外推地圖座標、門、按鈕、怪物、戰鬥或完整LEVEL1路線。
原版畫面不提交；真實資料與全庫回歸通過後維持CONFORMED。
