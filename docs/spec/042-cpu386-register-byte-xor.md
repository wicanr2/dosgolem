# 042 — 386 暫存器位元組 XOR

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 034`](../re/034-fd2-second-callback-xor.md)

- 實作 `30 /r` 的 `mod=3` 暫存器對暫存器形式。
- 來源及目的暫存器依 ModRM 的 `reg` 與 `r/m` 欄位選取，必須支援低位與高位
  八位元暫存器，且不得改寫目的暫存器以外的位元。
- 結果依 8 位元邏輯運算更新 ZF、SF 與 PF，清除 CF、OF 與 AF。
- 記憶體形式及新的前綴組合不由本切片授權，遇到時維持失敗即關閉。

驗收包含獨立 `xor bl,bl` 單元測試，以及固定雜湊 FD2 從 LE 入口自然越過
`0x460DF` 的整合測試。

2026-09-06：單元測試、固定雜湊整合測試與全套 Go 回歸通過；探針於 331 步
抵達 `0x460E1`，EBX=`0x53900`、ZF=1。
