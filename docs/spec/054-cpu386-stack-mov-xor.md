# 054 — 386 堆疊 MOV 與暫存器 XOR

狀態：**CONFORMED**  
日期：2026-09-06  
前置：[`RE 046`](../re/046-fd2-third-callback-fs-scan-setup.md)

- `89 /r` 新增 `mod=1, r/m=EBP`、disp8 的 32 位元寫入，使用預設 SS 描述子；
  其他新記憶體形式維持失敗即關閉。
- `31 /r` 支援無前綴 `mod=3` 暫存器 XOR，結果寫入 r/m32 並更新邏輯旗標；
  記憶體形式與前綴維持失敗即關閉。
- 固定 FD2 從 LE 入口自然抵達 `0x4CC24`，驗證 `[EBP-4]=0`、EAX=`0x30`、
  ESI=0、EBP=`0x55680`、ESP=`0x5567C`、ZF=1。

驗收包含獨立堆疊寫入與 XOR 單元測試、固定雜湊整合測試及探針收據。

2026-09-06：兩個單元測試、固定雜湊整合測試、探針及全套 Go 回歸通過；
探針於 476 步抵達 `0x4CC24`，local=0、EAX=`0x30`、ESI=0、ZF=1。
