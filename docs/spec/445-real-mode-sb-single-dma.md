# 445 — 實模式 SB 單次 8 位元 DMA 與 IRQ7

日期：2026-10-22

## 1. 規則

`-sound-blaster` 開著時，實模式的 `Machine` 有第一組 DMA 控制器，DSP `14h` 啟動通道 1 的單次傳輸，
傳完送 IRQ7。

| 項目 | 行為 |
|---|---|
| DMA 埠 | 00h–07h、0Ah–0Fh、頁埠 81h／82h／83h／87h 由 `DMA8237` 處理（與保護模式同一份實作）。SB 不存在時這些埠照舊不處理 |
| 開始條件 | DSP `14h` 收到長度高位時：通道 1 模式 48h（單次、記憶體讀）、未遮蔽、位址與計數兩個 byte 都寫過、頁寫過、取樣率已知、長度 ≤ 計數＋1。條件同 `LEOPLPorts.startDMA`。不成立就拒絕並計入 `SBDMARejects` |
| 時間 | 一個取樣 ＝ `StepsPerSecondNow()` × `RateDenominator` ÷ `RateNumerator` 道指令，開始時取整數的每秒指令數。傳輸中程式改 PIT 分頻，要到下一次傳輸才生效 |
| 每個取樣 | 由頁＋目前位址讀一個 byte（記入 `SBPCM`，最多 1 MB），位址加一、計數減一 |
| 終點 | 計數由 0 減成 FFFFh；單次模式設通道遮罩。全部送完：DSP 8 位元中斷來源立起（混音器 82h bit0），IRQ7 掛起 |
| IRQ7 派送 | IF＝1 且 8259 遮罩 bit7＝0 時以 `int 0Fh` 送出。向量段仍是 `StubSeg` 時不送也不丟（`IRQ7Stalls`），同 `keyTick` |
| 優先序 | 同一道指令 IRQ0 也到期時先送 IRQ0；ISR 關著 IF，IRQ7 留到返回之後 |
| DSP 重設 | 取消傳輸與掛起的 IRQ7 |
| 狀態檔與快照 | DMA 暫存器、DSP 取樣率與中斷來源、傳輸進度一起存。舊狀態檔沒有這一段：讀成「沒有傳輸、沒有掛起」 |

不做：自動初始化（`1Ch`、`C6h`）、16 位元、暫停恢復、第二組 DMA、8259 的服務中位元與 EOI。
實模式 `Machine` 對 IRQ0 也不模擬 EOI，這裡保持一致。收到不支援的命令照舊被 DSP 拒絕。

依據：

- 8237A 單次模式在終點設遮罩、計數由 0 減成 FFFFh：DOSBox-X `e0b4287` `src/hardware/dma.cpp`
  第 514–546 行（`currcnt == 0xFFFF` 時 `ReachedTC`，非自動初始化時 `masked = true`，附 8237A 資料表引文）。
- 單次 8 位元 DMA DAC 傳完送 8 位元中斷：同版 `src/hardware/sblaster.cpp` 第 2113–2118 行
  （`case 0x14` → `DSP_PrepareDMA_Old(DSP_DMA_8,false,…)`）與第 843–860 行 `SB_OnEndOfDMA`
  （`SB_RaiseIRQ(SB_IRQ_8)`，單次傳輸結束 `dma.mode=DSP_DMA_NONE`）。
- 讀 22Eh 清 8 位元中斷來源：既有 `SoundBlasterDSP.In8`。

## 2. 觸發案例

智冠中文版《魔法門 V》`XEEN.DAT`（MM5 目錄，與 MM4 `XEEN.CC` 合併執行）自帶 SB 驅動，載在 `8CC6:0000`，
IRQ7 向量 `8CC6:0236`。

1. 進入鐵匠鋪時驅動在 `8CC6:01D5`、`8CC6:01FD` 依序寫 DMA `0A←05 0C←00 0B←49 02←20 02←B1 83←07 03←75 03←3E 0A←01`、
   PIC `21←00`、DSP `40 BC 14 75 3E`：頁 07h 位移 B120h、15990 bytes、約 14706 Hz。
2. 驅動把「播放中」旗標 `[8CC6:0023]` 設成 1。ISR `8CC6:0236` 呼叫 `022B`（`out 0Ch; in 03h; in 03h`），
   計數是 FFFFh 才把旗標清 0。
3. 離開商店時，遊戲在 `0B62:0809`–`082D` 的迴圈經 `273C:0081`、`3C20:8509` 呼叫驅動入口 `8CC6:0003`
   功能 1，讀回旗標；1 就繼續等。

修改前 DSP `14h` 的長度高位被拒（`StartDMA` 是 nil），IRQ7 從未送出，旗標停在 1，遊戲在離開商店後
停住：4 億道指令內沒有任何滑鼠輪詢、檔案存取或畫面寫入，第 2700000000 道時 `[8CC6:0023]`＝1。

## 3. 驗收

1. 契約測試 `internal/machine/sb_dma_real_test.go`：照 §2 第 1 步的埠序列啟動 100 bytes，IRQ7 處理常式
   恰好跑一次，終點後讀回計數 FFFFh、位址加 100，22Eh 清掉中斷來源；取樣時間落在預期指令數內，
   `SBPCM` 為緩衝區內容；遮蔽中與向量指 stub 時留著、放行後送出；DSP 重設取消；DMA 沒設時拒絕；
   播到一半存狀態檔或快照，讀回後 IRQ7 在同一道指令送出。
   反面對照：同一支契約測試在基底 `e78d389` 上跑 2000 萬道指令，IRQ7 處理常式一次都沒跑。
2. `go test ./...` 全綠（Xvfb）。
3. 整合：§2 的案例離開商店後回到地圖畫面並繼續輪詢滑鼠。
