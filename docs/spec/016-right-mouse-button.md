# 016 — 滑鼠右鍵

狀態：READY
日期：2026-09-07

## 問題

`Click` 只送左鍵（`EvLeftDown`／`EvLeftUp`），`-clicks` 也只有左鍵。
DOS 遊戲普遍拿右鍵當「取消／關閉目前視窗」，只有左鍵就有一整類狀態
到不了——而且到不了的樣子是**畫面完全不動**，跟「點錯位置」分不出來。

實例：《銀河英雄傳說III SP》的報告視窗是 modal 迴圈，
從遊戲自己的事件佇列取事件，`type==1`（左鍵）拿去做命中測試，
`type==2` 直接跳出迴圈。`type` 由它的滑鼠回呼從按鍵狀態位元換算：
bit7（左）換出 1／4，bit5（右）換出 2／8。**沒有右鍵就關不掉那個視窗**，
於是它底下五個視窗（星圖、戰略命令列、左下、右側資訊、右上）
一個都點不到，因為命中測試會先問「這個座標最上層是哪個視窗」。

## 介面

程式化：

```go
o.Click(x, y, oracle.Right())      // 右鍵
o.Click(x, y)                      // 預設仍是左鍵
```

命令列：

```
-rclicks "x,y,at[,hold];..."       // 語法與 -clicks 相同，送右鍵
```

`-clicks` 與 `-rclicks` 可以同時給，各自照步數排程。

## 語意

| | int 33h 的按鍵位元（`BX`）| 按下事件 | 放開事件 |
|---|---|---|---|
| 左鍵 | bit0 | `EvLeftDown` (0x02) | `EvLeftUp` (0x04) |
| 右鍵 | bit1 | `EvRightDown` (0x08) | `EvRightUp` (0x10) |

按下時把該位元設起來、放開時清掉；`Press`／`Release` 的計數各按鍵分開。
其餘時序（hover → hold → settle）與左鍵完全相同，理由見 `005` §4：
遊戲輪詢的頻率很低，按下與放開隔太近會整段被跳過。

## 邊界

按鍵是**輸入的一部分**：收據要記下哪一次點擊是右鍵，否則同一組座標與
步數重跑會得到不同的結果。
