```text
0x460EF  58     pop eax
0x460F0  8A C4  mov al,ah
0x460F2  3C 03  cmp al,3
0x460F4  75 07  jnz 0x460FD
```

前段已證實堆疊控制字為 `0x037F`，所以 `pop eax` 後 EAX=`0x037F`；將 AH
複製至 AL 後 EAX=`0x0303`，與 3 比較得到 ZF=1，`JNZ` 不跳轉而抵達
`0x460F6`。`0x460A2` 的語意及這個分類值的高層名稱尚未在本切片證實。

「此分支屬於 x87 能力分類」為**強推論**；本證據不宣稱完整模擬 x87 或
