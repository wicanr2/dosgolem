# 034 — FD2 第二個啟動回呼清除 BL

日期：2026-09-06  
證據等級：**已證實**（固定雜湊原始位元組與自然執行路徑）  
輸入：`FD2.EXE`，大小 `357074`，MD5 `b97caf2239a27a896069d03549d96e1e`，
SHA-256 `222b7d067ad4450eb9c5f6e6bce1797d54bb050417ba39ced6067f8039f28c4f`  
工具：dosgolem `feat/fd2-parity`，基線提交 `4cc2a0b`  
位址空間：dosgolem 載入 LE 映像後的 32 位元線性位址

第二個啟動回呼的絕對位址閘門不跳轉後，下一條原始指令為：

```text
0x460DF  30 DB  xor bl,bl
0x460E1  88 1D F5270500  mov byte ptr [0x527F5],bl
```

`30 DB` 將 BL 清為零並依 XOR 結果更新邏輯旗標；它不改變 EBX 的其餘位元組。
`0x527F5` 的高層語意仍為**未知**，本證據只授權 CPU 指令與可觀察的零值寫入，
不授權替該全域變數命名。
