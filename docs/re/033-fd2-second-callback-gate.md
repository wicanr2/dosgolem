# 033 — FD2 第二個啟動回呼絕對位址閘門

日期：2026-09-06  
證據等級：**已證實**（固定雜湊記錄、分派器重掃、原始位元組、記憶體閘門）  
輸入：`FD2.EXE`，大小 `357074`，MD5 `b97caf2239a27a896069d03549d96e1e`，
SHA-256 `222b7d067ad4450eb9c5f6e6bce1797d54bb050417ba39ced6067f8039f28c4f`  
工具：dosgolem `feat/fd2-parity`（提交前基線 `881b39a`）及其固定雜湊整合測試  
位址空間：dosgolem 載入 LE 映像後的 32 位元線性位址

第一筆記錄標記後，分派器自然重掃並選中：

```text
record 0x539C8 = 00 02 D5 60 04 00
callback pointer = 0x460D5
```

回呼開頭：

```text
0x460D5  53                       push ebx
0x460D6  80 3D F4270500 00        cmp byte ptr [0x527F4],0
0x460DD  75 33                    jnz 0x46112
0x460DF  30 DB                    xor bl,bl
```

固定載入狀態 `[0x527F4]=0`，`CMP` 產生 ZF=1，`JNZ` 不跳轉並抵達
`0x460DF`。第一筆記錄此時已由 `00` 改為 `02`，第二筆仍為 `00`，證明執行
路徑是第一回呼返回後由分派器重掃所得，不是測試直接注入第二回呼位址。

後續位元組含有 x87 初始化與控制字檢查，故「這是 x87 能力探測」目前列為
**強推論**；`0x527F4`、`0x527F5` 與 `0x52830` 的高層名稱仍為**未知**，不可因
本切片可執行就替它們命名。
