# 009 — 在大地圖上點一個據點：三道閘，兩道是靜默的

日期：2026-09-05
狀態：已解，行軍指示第一次走完整條流程

---

## 1. 症狀

走到「請指示行軍目標之據點。」之後，把游標放到城上按下去——**完全沒反應**。
沒有錯誤、沒有訊息、畫面一個像素都不變。

## 2. 三道閘

臥龍傳選據點的等待迴圈是 `sub_1703C`（IDA 0x1703C）：

```asm
loc_17048:
    call sub_11F7F            ; 更新鏡頭與游標，順便算出「游標在第幾格」
    call sub_1E453            ; 命中測試：al = 熱區碼，bx = 1 左鍵／2 右鍵
    cmp  bx, 2 / jz  → stc    ; 右鍵取消
    and  al, al / jz  loc_1706F
    …                         ; ← al ≠ 0：游標壓在熱區上，**這一圈什麼都不問**
loc_1706F:
    and  bx, bx / jz  →       ; 沒按鍵
    call sub_1709E            ; 這一格是不是據點？CF=0 是
    jnb  → 回傳
```

`sub_1709E`（IDA 0x1709E，77 B）：

```asm
ds = word_10D44 + word_1989C × 24    ; 每列 384 格 ＝ 24 個節
al = [word_1989A]                    ; 該格的圖塊編號
cmp al, 0CBh / jb  → stc             ; ← 閘一：圖塊要落在 0CBh..0D3h
cmp al, 0D4h / jnb → stc
bx = 0
loop: cmp [bx+848h], word_1989A      ; ← 閘二：據點表登記的 X
      jnz next
      cmp [bx+84Ah], word_1989C      ;          與 Y 都要相等
      jz  → clc
next: bx += 20h / jmp loop
```

⇒ **一座城只有「登記的那一格」按得到**，16×16 像素。城的圖形有 4×4 格大，
所以「點圖示中間」有 15/16 的機會落空。

## 3. 兩個靜默的坑

### 3.1 格座標是**兩次捨去的和**，不是滑鼠座標除以 16

`word_1989A`／`word_1989C` 由 `sub_11F7F` 算好：

```
格 ＝ ⌊鏡頭 ÷ 16⌋ ＋ ⌊畫面座標 ÷ 16⌋
```

兩次無條件捨去**各吃掉一點**，所以鏡頭不是 16 的倍數時，
自己拿世界座標除 16 會差一格。實測：鏡頭 (2961,1345)、畫面游標 (639,399)、
滑鼠 (3600,1744)，遊戲算出來是第 (224,106) 格，而 3600÷16 ＝ 225。

⇒ `wolong.CursorTile()` 直接讀那兩個字，`PointAtTile()` 用**閉迴路**補：
每一輪問遊戲「你算在第幾格」，差多少補多少。**不要開路換算。**

### 3.2 游標不能停在熱區上

滑鼠座標在大地圖上是**世界座標**（findings/006 §3），推到視野外鏡頭就跟過去，
而鏡頭跟到底之後**游標就釘在畫面角落**。右下角是軍團情報視窗的熱區 `#31`
（x 432..639 y 192..399），左下角是訊息窗 `#30`——
`sub_1703C` 看到 `al ≠ 0` 就**根本不會**去問那一格是不是據點。

⇒ `PointAtTile()` 先把鏡頭捲到「目標格出現在畫面中央」，再在畫面內微調。
捲鏡頭沒有專用介面——**鏡頭是被游標推著跑的**，所以「捲到某處」
就是「把滑鼠推到那個位置的畫面邊緣外」。

## 4. 第三個坑在觀測工具自己身上：`At` 比錯了東西

同一次執行裡，`OnCall(0x11B5A)` **攔到了**，而
`RunUntil(At(o.IDA(0x11B5A)))` 跑滿六億道指令說沒到。

成因：`OnCall` 比線性位址，`At` 比 `Addr` 結構。真實模式下同一個 byte
有無數種 `段:偏移` 寫法（`02C5:000A` 與 `0200:0C5A` 是同一個位址），
程式走到哪一種由呼叫端當時的 CS 決定——不是我們挑的那一種。

⚠ **這個錯誤的形狀與「那段程式碼真的沒被執行」一模一樣**：
兩者都是跑滿預算才回錯。已修成比線性位址，回歸測試
`TestAtComparesLinearAddress` 做過突變（改回比結構就紅）。

## 6. 加了什麼

| 名稱 | 用途 |
|---|---|
| `wolong.CursorTile` | 讀遊戲算出來的「游標在第幾格」 |
| `wolong.PointAtTile` | 閉迴路把游標停到某一格，且避開熱區 |
| `shot` 的 `tile:TX,TY` | 上面那一支的腳本動作 |
| `shot` 的 `ipeek:LIN:N` | 讀 IDA 線性位址（`cs:word_XXXX` 用 `peek` 讀不到）|
| `shot` 的 `runto:LIN[,N]` | 跑到程式走到某個位址——**即時制的取樣點寫成事件** |
